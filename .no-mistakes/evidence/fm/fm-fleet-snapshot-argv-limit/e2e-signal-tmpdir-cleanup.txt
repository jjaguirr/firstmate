--- Note on the EXIT-only baseline above (Linux, bash 5.1.16) ---
On this platform the EXIT-only build still removed the directory: bash defers a
fatal signal that arrives while it waits on a foreground child (jq), then runs
the EXIT trap. The user-visible difference the fix makes on this platform is the
death itself. Repeated twice for SIGINT against the EXIT-only build:
  EXIT-only run 1: SIGINT -> status 0; leftover: <none>
  EXIT-only run 2: SIGINT -> status 0; leftover: <none>
The EXIT-only build swallows SIGINT and runs to completion (status 0), so
Ctrl-C through bin/fm-fleet-view.sh did not stop the snapshot. The fixed build
dies by the signal it was sent: 130 (INT), 143 (TERM), 129 (HUP), and removes
the temp directory on each.
